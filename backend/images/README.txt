HOW TO ADD REAL PRODUCT PHOTOS
==============================

EASIEST: in the backend folder run (needs internet, takes ~2 minutes):

    python download_images.py

It downloads a free photo for every product from Wikimedia Commons and saves the
photo credits in credits.json (shown on the product page). Refresh the website.

To use your own photo for a product instead (or for any it couldn't find):

1. Save a photo of the product in THIS folder (backend/images).
2. Name the file with the product's SKU code from the list below, e.g.  iph16.jpg
   Allowed types: .jpg  .jpeg  .png  .webp
3. Refresh the website. The photo replaces the emoji automatically (no restart needed).

Tips: use a square image with a white or plain background (about 500 x 500 px).
Only use photos you are allowed to use (e.g. the manufacturer's press images or your own photos).
